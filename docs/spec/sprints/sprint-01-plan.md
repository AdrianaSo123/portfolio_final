# Sprint 01 Plan

Date: 2026-04-15

## Goal

Polish the portfolio experience so it feels calm, professional, and conversion-focused.

## Scope

- Refine visual hierarchy and spacing.
- Keep project cards stacked and readable.
- Maintain brand consistency with So Studio.
- Preserve accessibility guardrails.

- Validate final layout and typography on desktop and mobile.

- Run lint, build, and accessibility checks.

- Motion polish can conflict with accessibility if overused.

## Definition of Done

- UI feels less overwhelming and easier to scan.
- Required project CTAs are present and clear.
- Lint and build pass.
- Accessibility scan remains green.
